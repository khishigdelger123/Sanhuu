# Санхүү — Хувийн орлого · зарлагын бүртгэл

Жижиг, хурдан, утасны дэлгэцэнд тохирсон web app.

- Орлого / Зарлага бүртгэнэ
- Үлдэгдэл автоматаар тооцогдоно
- Мэдээлэл таны утсан дээр хадгалагдана (localStorage)
- Интернетгүйгээр ажиллана (нэг удаа нээгдсэний дараа)

## GitHub Pages дээр ажиллуулах

1. Шинэ repository үүсгэнэ (жишээ: `sanhuu`)
2. Энэ `index.html` файлыг repository-д оруулна (root дээр)
3. **Settings → Pages → Source** → `Deploy from a branch` → `main` / `root` сонгоод Save
4. 1–2 минутын дараа линк гарч ирнэ:
   `https://<таны-username>.github.io/sanhuu/`

## iPhone дээр app шиг болгох

1. Safari-аар дээрх линкийг нээнэ
2. Share → **Add to Home Screen**
3. Home Screen дээр icon гарч ирнэ

## Анхаарах зүйл

- Мэдээлэл зөвхөн таны утсан дээр хадгалагдана. Browser cache цэвэрлэвэл устана.
- Нууцлалтай: сервер рүү юу ч илгээгддэггүй.
